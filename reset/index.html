01. Full-Funnel Architecture

단순 광고 집행을 넘어, 타겟 페르소나 정의부터 메시지 가설 검증, 그리고 전환 이후의 리텐션까지 고려한 전체 퍼널을 설계했습니다. 특히 AI를 활용해 전환 완료 후의 언드 페이지와 리텐션 이메일 HTML을 직접 퍼블리싱하여 세계관 몰입도를 유지했습니다.

[Ad → Landing → End → Email 단계별 전략 도표]

02. Data-Driven Optimization

GTM을 통해 스크롤 및 클릭 이벤트를 세밀하게 트래킹하여 사용자 행동 패턴을 분석했습니다. 플랫폼 수치가 아닌 GA4 활성 사용자 기준으로 퍼널별 실제 전환율을 산출하여 캠페인의 실질적인 효율을 검증했습니다.

Key Insights

  • 메시지 일관성: 광고 소재부터 이메일까지 동일한 세계관 톤을 유지하여 이탈 최소화
  • 효율적 타겟팅: 자동/수동 타겟팅 실험을 통해 전환이 집중되는 페르소나-메시지 조합 확인
  • 기술적 자동화: 이메일 및 문자 자동화를 연동하여 예약 데이터 기반의 CRM 기초 마련
